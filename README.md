# 澎湖海路 · 明末海盗原型

这是一个手机优先、无需安装依赖的 HTML5 回合制游戏。可以直接双击 `index.html`，使用 Chrome、Edge、Safari 等现代浏览器游玩。纯前端离线运行，不需要账号。

## 开始游玩

**在线试玩（推荐分享给朋友）：** [打开澎湖海路](https://yangfolker.github.io/pirate-sim-demo/)。手机、平板、电脑均可通过浏览器直接游玩，无需安装，也无需与开发电脑连接同一个 Wi-Fi。

**本机：** 双击 `index.html`。也可双击 `start.cmd`，保持命令窗口开启，在浏览器访问 `http://localhost:4173`。

**手机：** 手机与电脑连接同一 Wi-Fi，电脑双击 `start.cmd`。在手机浏览器输入窗口里显示的 `Same-Wi-Fi phone` 地址。局域网连接能否成功取决于设备网络和现有防火墙设置；本项目不会修改系统设置。双击 HTML 的方式只用于本机；手机需要访问上述服务器。

无需 `npm install`。开发验证命令：`node --test tests/engine.test.js`。服务器命令：`node server.js`。

本局与参数保存在当前浏览器的 localStorage 中。不同浏览器、设备、`file://` 和 HTTP 地址的存档相互独立；隐私浏览或限制存储的浏览器可能无法保存。页面会提示保存不可用。

## GitHub Pages 发布

仓库：[YangFolker/pirate-sim-demo](https://github.com/YangFolker/pirate-sim-demo)。在仓库的 **Settings → Pages** 中选择 **Deploy from a branch**，分支为 **main**，目录为 **/ (root)**。根目录的 `.nojekyll` 让 GitHub 直接发布静态网页，无需安装依赖或构建。

后续修改代码后，运行 `node --test tests/engine.test.js` 验证，再提交并推送到 `main`。GitHub Pages 会自动更新同一个试玩地址，可在仓库的 Actions 页面查看发布状态。朋友重新打开或刷新页面即可加载新版本，浏览器里的存档会继续保留；清理浏览器网站数据则会删除本机存档。

GitHub Pages 不提供多人联机或云存档，每位朋友都有独立航程。微信内置浏览器的访问情况取决于微信与当地网络；如无法加载，可复制链接到手机系统浏览器打开。

## 第一段建议试玩路线

1. 先在澎湖看一下补给、货舱和工钱。开局 150 两、16 人、85 点补给。
2. 用「海域全图」找泉州，再点「回到船位」。向西北逐格航行。
3. 港口买 12 担粮食，回澎湖点击交粮。也可接近海岸，夺粮并触发宗室支线。
4. 澎湖东侧初始可见一艘荷兰商船，用它测试劫掠或护航。它前往荷兰据点，护航到站后才结算声望和银两。
5. 港口服务下方点击「船坞 · 升级船体 / 火炮」，选择船壳、火炮、货舱与帆装。最多安装 3 件，形成取舍。页面底部的船舱装备页也可操作。

地图可以拖动；点格子查看，点「驶入此格」移动。WASD / 方向键也能移动。遭遇、战斗优先处理。海上可查看船舱并以粮食补给。港口买卖不消耗航海日。

**调整本局工资：** 点击地图上方士气栏旁的「调整工资」。每人每期可设为 0～2 两，支持一位小数；＋ / − 每次调整 0.5 两。面板会预览士气、伤害比例、按当前人数计算的总额与下次发薪日期。点「保存本局工资」后士气与战斗力立即生效，银两在下一次发薪日扣除。取消不改变工资，保存也不立即扣钱或推进时间。工资仍在原定日期按当时船员数结算，总额不足一两向上取整；本局调整随存档保存，不改动齿轮里的新开局默认工资。

## 已实现

- 从澎湖出发，8 方向逐格移动；3×3 实时视野、探索记录、隐藏暗礁、港口疫病。
- 简化真实地理海图，覆盖中国东南沿海、台湾、朝鲜、日本、琉球、越南及菲律宾海域；13 个可达地点。
- 港口差价贸易、有限库存、价格浮动、货舱容量、补给、工钱、招募与港口修船。
- 所有港口每次点击招募 1 名船员、花费 5 两，满员或钱不够时按钮禁用。
- 设定的每人工资决定士气与攻击伤害；地图上方和战斗面板都显示士气与伤害比例。
- 航程中可直接调整每人每期工资，预览士气、伤害、总额与发薪日期，保留原有发薪周期。0 工资或银两不足都不会导致船员辞职。
- 商船劫掠 / 护航 / 放行；官船与海盗；强敌追击；弃货逃跑。
- 回合制炮击、接舷、机动与火攻；战斗失败、触礁沉船、无船员或哗变结束本局。
- 声望解锁旗帜；挂旗影响港口有效关系；周期性随机外交变化。
- 筹粮主线、朱氏宗室逃难支线、泉州平盗委任；郑芝龙的传话船与海怪传说事件。
- 自动存档、死亡重开、种子复现、图形化参数面板、可替换的 SVG / PNG 素材。

## 调整数值与替换素材

**不写代码：** 点右上角齿轮。可修改初始银两、船员、船体、补给、货舱、改装位、日耗、工资、哗变概率、舰船密度、暗礁密度、外交周期、任务需求、疫病损失、炮击威力、旗帜门槛、零士气时伤害比例。点击保存后在新一局生效。可导出 JSON 用于记录和分享数值方案。

素材放进 `assets` 目录。参数面板填写相对路径，例如 `assets/my-ship.png`、`assets/my-captain.png`。船只推荐透明正方形；船长推荐竖幅。也可以直接用新图片替换原有 SVG 文件的内容并保持格式。更换素材后重开，必要时刷新页面以清除浏览器图片缓存。

**进一步编辑内容：** `config.js` 保存货物、装备、事件文案与默认数值；`world.js` 保存海岸和港口坐标。网页里保存的个人参数会覆盖默认配置；修改 `config.js` 后在面板点「恢复默认参数」并重开。

常用参数的范围在 `app.js` 的 `fields` 中定义。新增装备 / 货物需要同步考虑引擎状态，当前参数面板用于数值调节与素材替换，不是完整的内容编辑器。

## 当前设计口径

- 暂定 1644 年。粮荒与逃难开场为合理的虚构情境，不指称某次真实事件。朱氏一家为虚构人物；“农民起义追杀福建宗室”的具体桥段改为乡间兵乱逃难，避免误作当地确定史实。
- 开局承认荷日已有通商，以及荷兰在大员、鸡笼的据点。后续外交是本局推演，数值本身不是历史史料。这个原型尚未模拟南明、清军推进或郑氏复杂的独立政治地位。
- 地图约每格 0.4°，海岸为手工粗略轮廓。港口位置与入港规则为可玩性进行了简化；日本等地的实际海禁、贸易资格与出入限制未完整模拟。
- 自身声望决定能否领旗。挂旗后，港口有效关系 = 对该势力声望 + 旗帜外交修正。有效关系低于或等于 −25 时不提供服务。友善往来本身不会自动视为政治归属。
- 港口操作与战术战斗不额外走日；航行与抛锚等候走日。每 6 日发工资。供给不足将减员并可能哗变。
- 士气 = 每人工资 ÷ 2 × 100；工资范围 0～2 两，对应士气 0～100。默认攻击伤害在士气 0 时为正常的 50%，士气 50 时为 75%，士气 100 时为 100%，中间线性变化，伤害取整且至少为 1。炮击、接舷、牵制、火攻及持续燃烧均按每次行动开始时的士气折算；敌方伤害不额外放大。调整工资立即影响士气，持有银两与船员数量不影响士气。
- 工资为 0 时不扣钱，船员不辞职。发薪时银两不足则只扣剩余银两，在日志记录应发、实发与缺额，不扣船员、不改工资或士气。补给不足造成的饥饿减员与哗变仍然适用。
- 旧存档自动迁移到工资士气规则，删除旧储银阈值，工资超过 2 两时调整为 2 两；既有银两、船员、位置、任务与其他参数不重置。无需再过一天或重新开局。
- 货舱粮食与船上补给是两类资源。1 担粮食可转成 10 点补给。逃跑丢弃全部货物，同行任务人物保留；护航被中断。
- 同一海岸劫掠后 12 日恢复，招募后 7 日恢复。每轮港口疫病对同一次疫情只扣人一次。
- 已完成委任后可继续航行；当前没有强制胜利结算和局外成长。

## 文件分工与后续迁移

- `engine.js`：无 DOM 的规则与状态，引擎测试可以直接运行。
- `world.js`：地理、港口、网格寻路。
- `config.js`：默认平衡数值、文案与素材路径。
- `app.js` / `style.css`：浏览器交互、响应式页面和 Canvas 海图。
- `tests/engine.test.js`：任务闭环、视野、战斗、护航、贸易、外交、灾害、存档等测试。
- `server.js` / `start.cmd`：电脑及同 Wi-Fi 手机试玩服务。

微信小游戏尚未接入。本版先验证 HTML5 玩法；迁移小游戏需要替换页面 UI、文件 / 存储接口与平台启动流程。迁移到游戏引擎时可以参考或复用独立的规则、状态与数据，但地图显示和控件要重新接入。

优先收集试玩反馈：是否容易找到粮食；交易与劫掠哪个更有趣；补给压力是否合理；连续事件是否繁琐；挂旗的利弊是否可理解；死后是否愿意再开一局。
